## 📖 About

MeshLab is developed by the Visual Computing Lab of ISTI, part of the Italian National Research Council (CNR). It has been a long standing part of the open source graphics ecosystem and is widely used in cultural heritage digitization, academic research and reverse engineering. The application handles point clouds, triangle meshes and textured models, and it ships a large collection of filters for decimation, remeshing, smoothing, hole filling and normal recalculation. Recent builds rework the rendering pipeline, improve support for modern graphics drivers on Windows and modernize the file import layer for popular scan and CAD exchange formats. If you came looking for a MeshLab download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes.

The interface is built around a viewport with dockable panels for layers, filters and mesh statistics. Most operations are one or two clicks from the filter menu, and every action can be undone while you iterate on a model. Batch processing lets you apply the same filter chain across a folder of scans, which is useful when a photogrammetry session produces dozens of chunks at once. Models can be exported to OBJ, PLY, STL, OFF, glTF and several other formats depending on the downstream pipeline.

**Good for:** 3D scanning hobbyists · cultural heritage digitization teams · reverse engineering engineers · academic researchers · photogrammetry users · game asset artists · CAD and prototyping professionals

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes without a message | Confirm the file finished downloading, then run it again from the Downloads folder. |
| App opens with a blank viewport | Update the graphics driver and confirm OpenGL 3.3 or newer is available. |
| Large scan file fails to import | Split the dataset or increase available RAM, then retry the import. |
| Viewport runs slowly on big meshes | Lower the on screen point and face display density in the preferences. |
| Textures look washed out after export | Verify the texture coordinates and the color space settings in the export dialog. |
| Mesh appears inverted or dark | Recalculate vertex normals from the filter menu and check face orientation. |
